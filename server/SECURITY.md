# Security Policy

## Supported versions

Only the latest release of `calmly-sync-server` receives security fixes.

## Reporting a vulnerability

**Please do not open a public GitHub issue for security vulnerabilities.**

Email **security@calmly.app** with:

1. A description of the vulnerability and its potential impact
2. Steps to reproduce or a minimal proof-of-concept
3. Any suggested mitigations if you have them

We will acknowledge receipt within **2 business days** and aim to provide a resolution timeline within **7 business days**. We will credit reporters in the release notes unless you prefer to remain anonymous.
